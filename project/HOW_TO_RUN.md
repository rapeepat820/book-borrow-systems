# ⚡ วิธีเร็วสุดบน Windows (คลิกเดียว)

ดับเบิลคลิกไฟล์ `START-HERE.bat` ในโฟลเดอร์โปรเจกต์ สคริปต์จะหา MySQL, นำเข้าฐานข้อมูล (ข้ามถ้ามีอยู่แล้ว), สร้าง `.env`, ติดตั้งแพ็กเกจ แล้วเปิดระบบกับเบราว์เซอร์ให้เอง
ต้องมี Node.js 18+ และ MySQL/XAMPP (เปิด MySQL ไว้) ก่อน — ถ้าขาดอะไร สคริปต์จะบอกเป็นภาษาไทย

# วิธีเปิดใช้งานจริงเพื่อทดสอบระบบ (สำหรับเครื่องตัวเอง / localhost)

คู่มือนี้เขียนแบบละเอียดทีละขั้นตอน สำหรับคนที่ไม่เคยรันโปรเจกต์ Node.js + MySQL มาก่อน
ใช้เวลาเตรียมเครื่องประมาณ 15-20 นาที

---

## สิ่งที่ต้องติดตั้งก่อน (ทำครั้งเดียว)

1. **Node.js** (เวอร์ชัน 18 ขึ้นไป) — ดาวน์โหลดที่ https://nodejs.org (เลือกปุ่ม LTS)
   - ติดตั้งเสร็จแล้วเปิด Command Prompt / Terminal พิมพ์ `node -v` ถ้าขึ้นเลขเวอร์ชันแปลว่าใช้ได้
2. **MySQL** — ถ้ายังไม่มี แนะนำติดตั้งผ่าน **XAMPP** (ง่ายที่สุด มี MySQL + phpMyAdmin มาให้พร้อม)
   - ดาวน์โหลดที่ https://www.apachefriends.org แล้วติดตั้งตามปกติ
   - เปิดโปรแกรม XAMPP Control Panel แล้วกด **Start** ที่แถว MySQL (ไม่ต้อง start Apache ก็ได้)
3. **โปรแกรมแก้โค้ด** เช่น VS Code (ไม่บังคับ แต่สะดวกเวลาแก้ `.env`) — https://code.visualstudio.com

## ขั้นตอนที่ 2: สร้างฐานข้อมูล

**ถ้าใช้ XAMPP:**
1. เปิดเบราว์เซอร์ไปที่ `http://localhost/phpmyadmin`
2. คลิกแท็บ **SQL** ด้านบน
3. เปิดไฟล์ `backend/database/schema.sql` ด้วยโปรแกรมแก้ไขข้อความ (Notepad ก็ได้) คัดลอกเนื้อหาทั้งหมด
4. วางลงในช่อง SQL ของ phpMyAdmin แล้วกด **Go / ไป**
5. จะเห็นฐานข้อมูลชื่อ `book_borrow_system` ถูกสร้างขึ้นพร้อมตารางและข้อมูลตัวอย่าง (หนังสือ 32 เล่มพร้อมรูปปกและรายละเอียดครบ, บริษัทขนส่ง 1 เจ้าที่เปิดใช้งาน)

**ถ้าใช้ MySQL แบบ command line:**
```bash
mysql -u root -p --default-character-set=utf8mb4 < backend/database/schema.sql
```
(สำคัญ: ต้องใส่ `--default-character-set=utf8mb4` ไม่งั้นข้อความภาษาไทยในฐานข้อมูลอาจกลายเป็นตัวอักษรมั่วเมื่ออ่านกลับมา)

> ถ้าเคยสร้างฐานข้อมูลนี้ไปแล้วตอนทดสอบรอบก่อน มีทางเลือกตามนี้:
> - **ถ้าไม่มีข้อมูลสำคัญอยู่แล้ว**: ลบตารางเก่าทิ้งก่อน (รัน `DROP DATABASE book_borrow_system;` ใน phpMyAdmin) แล้วรัน schema.sql ใหม่ทั้งหมด
> - **ถ้ามีข้อมูลอยู่แล้วไม่อยากลบ (เวอร์ชันก่อนมีที่อยู่แบบ dropdown/ค่าธรรมเนียมต่ออายุ)**: รัน `backend/database/migration_v2.sql`
> - **อัปเดตจากเวอร์ชันก่อนหน้านี้ (ก่อนมีรูปปกหนังสือ/รายละเอียดหนังสือ/บริษัทขนส่งเดียว)**: รัน `backend/database/migration_v3.sql` เพิ่ม (รันซ้ำได้ปลอดภัย) — ต้อง build+deploy frontend เวอร์ชันล่าสุดด้วย ไม่งั้นรูปปกจะขึ้น 404
> - **อัปเดตเพื่อเพิ่มหนังสือใหม่อีก 8 เล่ม**: รัน `backend/database/migration_v4.sql` ต่อจาก migration_v3.sql (รันซ้ำได้ปลอดภัย เช็คชื่อซ้ำก่อนเพิ่มให้อัตโนมัติ)
> - **เพิ่มหนังสือจริง 21 เล่ม (1984, Sapiens, The Hobbit ฯลฯ) พร้อมปกจาก Open Library**: รัน `mysql --default-character-set=utf8mb4 -u <user> -p <ชื่อฐานข้อมูล> < backend/database/migration_v5_real_books.sql` (รันซ้ำได้ปลอดภัย)
>   - ปกใช้ลิงก์ตรงไปยัง Open Library (`covers.openlibrary.org`) **ไม่ได้ดาวน์โหลดไฟล์ลงเครื่อง** ต้องมีอินเทอร์เน็ตตอนเปิดเว็บ ถ้าโหลดไม่ได้หรือไม่มีปกของ ISBN นั้น เว็บจะสลับไปแสดงปกที่สร้างอัตโนมัติแทนเอง
>   - ISBN/สำนักพิมพ์/ปีพิมพ์เขียนจากความรู้ ไม่ได้ตรวจกับเว็บจริง ก่อนนำเสนอควรเปิดดูทุกเล่มว่าปกตรงกับชื่อเรื่อง แล้วแก้ที่ตาราง `books` ได้เลย
>   - **ตรวจกับ Open Library อัตโนมัติ (รันบนเครื่องคุณ ต้องต่ออินเทอร์เน็ต)**: `cd backend && npm run verify-books` จะแสดงตารางเทียบชื่อ/ผู้แต่ง/สำนักพิมพ์/ปี/ลิงก์ปกของแต่ละเล่ม (ยังไม่แก้ข้อมูล) ถ้าพอใจรัน `npm run verify-books -- --apply` เพื่อเปลี่ยนปกเป็นลิงก์ที่ยืนยันว่ามีจริง (เก็บเป็นลิงก์ ไม่ดาวน์โหลดรูป)
>   - **เติมรูปปก/ปีที่พิมพ์/ฉบับที่/เล่มที่ให้อัตโนมัติ (ไม่ต้องรันคำสั่งเอง)**: แค่เปิดเซิร์ฟเวอร์ (`npm start` / `npm run dev`) ระบบจะเพิ่มคอลัมน์ที่ขาด จับคู่รูปปกกับหนังสือทุกเล่มที่ยังว่าง และเติมปีที่พิมพ์/ฉบับที่/เล่มที่ให้เอง เล่มที่ยังขาดจะไปดึงจากอินเทอร์เน็ตเบื้องหลัง ดูผลใน log ขึ้นต้น `[books]` หรือกดปุ่ม "เติมข้อมูลหนังสือทั้งหมดอัตโนมัติ" ในหน้าแอดมิน > จัดการหนังสือ (ปิดการทำงานตอนเปิดเซิร์ฟเวอร์ได้ด้วย `AUTO_FILL_BOOKS=false`)
>   - **ดึงรูปปก + รายละเอียดจาก API อัตโนมัติ (Open Library + Google Books)**: `cd backend && npm run enrich-books` (ดูตัวอย่างก่อน) แล้ว `npm run enrich-books -- --apply` เพื่อเติมปก/เรื่องย่อ/สำนักพิมพ์/ปีที่พิมพ์ให้หนังสือทุกเล่มที่ยังว่างหรือปกเสีย (ไม่เขียนทับของเดิม ยกเว้นใส่ `--force`) ใส่ `--download` เพื่อโหลดรูปมาเก็บใน `frontend/public/book-covers` แทนการเก็บเป็นลิงก์
>   - **เพิ่มหนังสือใหม่จากชื่อ**: `npm run enrich-books -- --type 1 --copies 3 "Dune" "Atomic Habits" --apply` (ระบบหาปก/ผู้แต่ง/เรื่องย่อ/สำนักพิมพ์/ปีให้เอง; ใส่ ISBN ได้ เช่น `"isbn:9780441172719"`)
>   - **ในหน้าแอดมิน**: ฟอร์มเพิ่ม/แก้ไขหนังสือมีปุ่ม "ดึงปกและรายละเอียดจากอินเทอร์เน็ตตามชื่อหนังสือ" กรอกชื่อแล้วกดได้เลย

## ขั้นตอนที่ 3: สร้างรหัสผ่านแอดมิน

บัญชีแอดมินตัวอย่างในฐานข้อมูลยังไม่มีรหัสผ่านจริง ต้องสร้างเอง 1 ครั้ง:

1. เปิด Terminal ไปที่โฟลเดอร์ `backend`
2. รันคำสั่ง (แก้ `mypassword123` เป็นรหัสผ่านที่ต้องการ):
   ```bash
   cd backend
   npm install
   node -e "console.log(require('bcrypt').hashSync('mypassword123', 10))"
   ```
3. จะได้ข้อความยาวๆ ขึ้นต้นด้วย `$2b$10$...` ให้ copy ไว้
4. ไปที่ phpMyAdmin → เลือกฐานข้อมูล `book_borrow_system` → ตาราง `users` → แก้แถวของ `admin@bookshop.local`
   นำค่าที่ copy ไว้ไปวางแทนในช่อง `password_hash` แล้วกด Go

ตอนนี้จะเข้าสู่ระบบแอดมินได้ด้วย: **อีเมล** `admin@bookshop.local` / **รหัสผ่าน** ที่ตั้งไว้ (`mypassword123`)

## ขั้นตอนที่ 4: ตั้งค่าและรัน Backend

```bash
cd backend
copy .env.example .env      # Windows (Mac/Linux ใช้: cp .env.example .env)
```

เปิดไฟล์ `.env` ที่เพิ่งสร้าง แก้ค่าตามนี้:
```
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=          <-- ถ้า MySQL ไม่มีรหัสผ่าน (XAMPP ค่าเริ่มต้นคือไม่มี) ปล่อยว่างไว้ได้
DB_NAME=book_borrow_system
JWT_SECRET=ตั้งข้อความอะไรก็ได้ยาวๆ
```

> 💡 **เรื่องการรับชำระเงิน (PromptPay):** ระบบใช้ QR PromptPay แบบรูปคงที่รูปเดียว (ไม่ได้สร้าง QR ใหม่ต่อรายการ)
> รูป QR และชื่อบัญชีอยู่ที่ `frontend/src/config/payment.js` — ถ้าจะเปลี่ยนเป็นบัญชีของตัวเอง ให้เอารูป QR
> จากแอปธนาคาร (หน้า "ขอ/รับเงิน") มาแทนที่ไฟล์ `frontend/src/assets/promptpay-qr.png` แล้วแก้ชื่อบัญชีในไฟล์นั้น
> เพราะ QR นี้ไม่ได้ฝังยอดเงินไว้ในตัว (ต่างจาก QR แบบสร้างต่อรายการ) หน้าชำระเงินจะโชว์ยอดที่ต้องโอนไว้ให้กรอกเอง

ส่วน `SMTP_*` (สำหรับส่งอีเมล) **ข้ามไปก่อนได้** ระบบจะยังทำงานปกติ แค่จะไม่ส่งอีเมลจริง (จะขึ้น log ใน terminal แทน)

> 📧 **อีเมลแจ้งเตือนที่ระบบส่งอัตโนมัติ (ผ่าน nodemailer):**
> - **ลืมรหัสผ่าน** — ตอนลูกค้ากด "ลืมรหัสผ่าน"
> - **พัสดุถูกจัดส่งแล้ว** — ตอนแอดมินอัปเดตสถานะจัดส่งเป็น "กำลังจัดส่ง" (พร้อมเลข tracking)
> - **ใกล้ครบกำหนดคืน** — รันอัตโนมัติทุกวัน 08:00 น. (หรือกดสั่งเองจาก Dashboard แอดมิน) สำหรับรายการที่ครบกำหนดคืนภายใน 2 วัน
> - **ได้รับแจ้งคืนหนังสือแล้ว** — ตอนลูกค้าอัปโหลดหลักฐานการคืน (แจ้งว่ากำลังรอแอดมินตรวจสอบ)
> - **ยืนยันคืนหนังสือสำเร็จ** — ตอนแอดมินตรวจสอบและกด "ยืนยันการคืนหนังสือ" (แจ้งว่าคืนเงินมัดจำให้แล้ว)
>
> 🔑 **ตั้งค่าให้ "ลืมรหัสผ่าน" ส่งอีเมลได้ (Gmail):**
> 1. เปิด **การยืนยันตัวตน 2 ขั้นตอน** ที่บัญชี Google ของคุณ
> 2. เข้า https://myaccount.google.com/apppasswords สร้าง **รหัสผ่านแอป** (ได้รหัส 16 ตัวอักษร)
> 3. แก้ไฟล์ `backend/.env` : `SMTP_USER=อีเมล Gmail ของคุณ` และ `SMTP_PASS=รหัสผ่านแอป 16 ตัว` (ห้ามใช้รหัสผ่าน Gmail ปกติ และห้ามส่งรหัสนี้ให้ใคร)
> 4. รีสตาร์ท backend แล้วทดสอบด้วย `cd backend && npm run test-mail -- อีเมลที่อยากให้ส่งไปหา`
> ถ้ายังไม่ตั้งค่า หน้า "ลืมรหัสผ่าน" จะแจ้งว่า "ระบบอีเมลยังไม่ได้ตั้งค่า" และลิงก์รีเซ็ตจะถูกพิมพ์ใน terminal ของ backend ให้คัดลอกไปเปิดเองได้ตอนทดสอบ

> ตั้งค่า `SMTP_USER`/`SMTP_PASS` ให้ครบเมื่อไหร่ อีเมลทั้งหมดด้านบนจะส่งจริงทันทีโดยไม่ต้องแก้โค้ดเพิ่ม (ถ้าใช้ Gmail ต้องใช้ "รหัสผ่านแอป" ไม่ใช่รหัสผ่านบัญชีปกติ — สร้างได้ที่ myaccount.google.com/apppasswords)

จากนั้นรัน:
```bash
npm run dev
```
ถ้าสำเร็จจะเห็นข้อความ `Server running on http://localhost:4000` — **เปิด terminal นี้ทิ้งไว้ ห้ามปิด**

## ขั้นตอนที่ 6: ทดสอบใช้งาน

> 🎨 **หน้าตาเว็บแบบใหม่ (มินิมอล):** รองรับทั้งมือถือและจอคอมพิวเตอร์ มี **โหมดมืด/สว่าง** (ปุ่มพระจันทร์/พระอาทิตย์มุมขวาบน
> จำค่าที่เลือกไว้ และตามค่าเริ่มต้นของเครื่องถ้ายังไม่เคยเลือก), **รายการโปรด** (กดหัวใจที่หนังสือ — เก็บในเบราว์เซอร์),
> ตัวกรอง/เรียงลำดับในหน้าแรก, แบนเนอร์เตือนเมื่อหนังสือใกล้ครบกำหนด/เกินกำหนดคืน และ skeleton ตอนโหลดข้อมูล
> ฟอนต์ใช้ Noto Sans Thai จาก Google Fonts (ถ้าออฟไลน์จะใช้ฟอนต์ของระบบแทนอัตโนมัติ)

### ฝั่งลูกค้า (http://localhost:5173)
1. กด **สมัครสมาชิก** → กรอกข้อมูล พร้อมเลือก**ที่อยู่จัดส่งผ่าน dropdown** (จังหวัด → อำเภอ/เขต → ตำบล/แขวง แล้วรหัสไปรษณีย์จะเติมให้อัตโนมัติ) — ต้องกรอกที่อยู่ให้ครบตอนสมัคร เพราะระบบจะใช้ที่อยู่นี้จัดส่งหนังสือให้อัตโนมัติทุกครั้งที่ยืมโดยไม่ถามซ้ำอีก (แก้ไขภายหลังได้ที่เมนู → แก้ไขโปรไฟล์)
2. หน้า **Home** จะเห็นการ์ดหมวดหมู่หนังสือ (มีรูป/สีต่อหมวด) และหนังสือตัวอย่างพร้อมปกที่ระบบสร้างให้อัตโนมัติ → ลองกดเลือกหมวดหมู่เพื่อกรองดู แล้วกดเข้าไปดูรายละเอียดเล่มใดก็ได้
3. กด **ยืมหนังสือเล่มนี้** → หน้านี้จะโชว์ที่อยู่จัดส่งที่ดึงมาจากโปรไฟล์ให้อัตโนมัติ (ไม่ต้องกรอกใหม่) เลือกบริษัทขนส่ง แล้วกด **ถัดไป: ชำระเงิน** (ตอนนี้ระบบจะสร้างรายการยืมไว้แล้ว รอชำระเงิน)
4. หน้าชำระเงินจะโชว์ **QR PromptPay** (รูปคงที่) พร้อมยอดที่ต้องจ่าย (ค่าส่ง + มัดจำ) และชื่อบัญชีผู้รับเงิน — เพราะ QR นี้ไม่ได้ฝังยอดเงินไว้อัตโนมัติ ตอนทดสอบสแกนจริงต้องกรอกยอดเงินเองให้ตรงกับที่แอพแสดง จากนั้น **แนบรูปสลิปการโอนเงิน** (รูปอะไรก็ได้สำหรับทดสอบ) แล้วกด **ส่งสลิปเพื่อยืนยันการยืม**
5. ไปที่แท็บ **หนังสือของฉัน** ด้านล่าง จะเห็นรายการที่เพิ่งยืม สถานะการชำระเงินจะเป็น "รอตรวจสอบสลิป" จนกว่าแอดมินจะยืนยัน → กด **ติดตามพัสดุ** เพื่อดู stepper สถานะการจัดส่ง (กำลังแพ็ค → กำลังจัดส่ง → ขนส่งกำลังนำส่ง → จัดส่งสำเร็จ)

### ฝั่งแอดมิน (http://localhost:5173/admin/login)
1. เข้าสู่ระบบด้วยอีเมล/รหัสผ่านแอดมินที่ตั้งไว้ในขั้นตอนที่ 3
2. ที่หน้า **Dashboard** ลองกดปุ่ม **"ส่งอีเมลแจ้งเตือนตอนนี้"** เพื่อทดสอบระบบอีเมล (ปกติรันอัตโนมัติทุกวัน 08:00 น. แต่ปุ่มนี้สั่งส่งได้ทันที) — หมายเหตุ: จะมีอีเมลจริงถูกส่งก็ต่อเมื่อมีรายการที่สถานะ "กำลังยืม" และกำหนดคืนอยู่ภายใน 2 วันข้างหน้าเท่านั้น ถ้าอยากทดสอบให้เจอผลจริง ให้ไปแก้ `due_date` ของรายการทดสอบผ่าน phpMyAdmin ให้เป็นวันพรุ่งนี้ก่อน
3. ไปที่เมนู **การยืม-คืน** จะเห็นรายการที่ลูกค้าเพิ่งยืม พร้อมสถานะ "รอตรวจสอบสลิป" → กด **ดูสลิป / ตรวจสอบ** เพื่อดูรูปสลิปที่ลูกค้าแนบมา แล้วกด **ยืนยันการชำระเงิน** (หรือ **ปฏิเสธสลิป** เพื่อให้ลูกค้าแนบใหม่)
4. กด **ดูที่อยู่จัดส่ง** เพื่อดูที่อยู่เต็มที่ลูกค้ากรอกไว้ตอนยืม
5. กด **อัปเดตสถานะจัดส่ง** → เลือก "กำลังแพ็คสินค้า" ก่อน แล้วค่อยๆ เปลี่ยนเป็น "กำลังจัดส่ง" (ต้องกรอกเลข tracking ตอนนี้) → "ขนส่งกำลังนำส่ง" → "จัดส่งสำเร็จ" เพื่อจำลองกระบวนการจัดส่งจริง แล้วสลับไปดูฝั่งลูกค้าว่า stepper อัปเดตตามหรือไม่
6. กลับไปฝั่งลูกค้า → หนังสือของฉัน → ลองกด **คืนหนังสือ** แนบรูปภาพอะไรก็ได้ (ระบบบังคับแนบรูปก่อนส่งได้เสมอ) → กด **ต่ออายุยืม** ก็ลองได้เช่นกัน (เลือกจำนวนวัน ระบบจะคำนวณค่าธรรมเนียมต่ออายุให้ทันที จากนั้นต้องสแกน QR จ่ายค่าธรรมเนียมแล้วแนบสลิป เหมือนตอนจ่ายเงินยืมหนังสือ)
7. กลับมาฝั่งแอดมินเพื่อกด **ยืนยันคืน + คืนมัดจำ** ที่รายการคืนหนังสือ ส่วนคำขอต่ออายุยืมให้กด **ตรวจสอบสลิปค่าธรรมเนียม** แล้วกด **ยืนยันชำระเงิน + ต่ออายุ** (ระบบจะบวกวันเข้ากำหนดคืนให้ทันที) หรือกด **ปฏิเสธคำขอ** เพื่อยกเลิกคำขอต่ออายุนั้น

## แก้ปัญหาที่เจอบ่อย

| อาการ | สาเหตุที่เป็นไปได้ | วิธีแก้ |
|---|---|---|
| `Error: connect ECONNREFUSED` ตอนรัน backend | MySQL ยังไม่ได้เปิด | เปิด XAMPP แล้วกด Start ที่ MySQL |
| หน้าเว็บขึ้น "เกิดข้อผิดพลาด" ตลอด | backend ไม่ได้รันอยู่ หรือรันคนละพอร์ต | เช็คว่า terminal backend ยังเปิดอยู่และไม่มี error สีแดง |
| เข้าสู่ระบบแอดมินไม่ได้ | ยังไม่ได้ตั้ง `password_hash` ตามขั้นตอนที่ 3 | ทำขั้นตอนที่ 3 ใหม่อีกครั้ง |
| Error `ER_BAD_FIELD_ERROR` เกี่ยวกับ `shipping_address` หรือ `shipping_status`/`payment_status` | เคย import schema.sql เวอร์ชันเก่าไปแล้ว | ลบฐานข้อมูลเดิม (`DROP DATABASE book_borrow_system;`) แล้ว import `schema.sql` ใหม่ |
| หน้าชำระเงินไม่ขึ้นรูป QR / ขึ้นแต่ยอดเงิน | ลืม build frontend ใหม่หลังแก้ไฟล์รูป QR | รัน `npm run build` ใน `frontend` ใหม่ (หรือถ้ารันด้วย `npm run dev` อยู่แล้วให้ลอง refresh หน้าเว็บ) |
| พอร์ต 4000 หรือ 5173 ถูกใช้งานอยู่แล้ว | มีโปรแกรมอื่นใช้พอร์ตนี้อยู่ | ปิดโปรแกรมนั้น หรือแก้ `PORT` ใน `.env` (backend) / ใช้ `npm run dev -- --port 5174` (frontend) |
| อัปโหลดรูปหลักฐานการคืนแล้วไม่ขึ้นรูป | เปิดเว็บผ่าน URL อื่นที่ไม่ใช่ localhost:5173 | ให้เปิดผ่าน `http://localhost:5173` เท่านั้น เพราะตั้ง proxy ไปที่ backend ไว้เฉพาะตอน dev |

ถ้าเจอ error อื่นนอกเหนือจากนี้ ให้ copy ข้อความ error สีแดงในหน้าต่าง terminal (backend หรือ frontend) มาส่งได้เลย จะช่วยดูให้ว่าเกิดจากอะไร
